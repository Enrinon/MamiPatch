# MamiPatch
A patch for the game 巴マミTPS

<h1 align="left">About</h3>

I've created a patch for the game 巴マミTPS which improves on several aspects of the original experience

<h1 align="left">Features</h3>

• Spanish translation.
• Improved Android 12+ compatibility.
• Full-Screen support

<h1 align="left">How to use?</h3>

One thing before I go: If you have a phone with a high-resolution display, the buttons may appear too small. I'll try to fix this in a future patch.

**You Need**:
• Original game APK
• APKTool M (or an alternative).
• Patch.zip

**Important**: 

• The patch contains only modified files, not the complete game.

To use my patch file which I'll leave below, you'll need to decompile your original game with a tool, in my case, I used APKTool M for this, but if you want, you can use another specialized program to decompile.

Well, you have to open your program if you have already downloaded it, look for a function called decompile (or "descompilar" in Spanish) and wait for a certain amount of time until the tool finishes decompiling, after the decompilation has finished, add the files from the zip to the decompiled folder (do not copy apktool.json if you didn't use APKTool M), after that, compile the project (set minsdk to 24 or higher and targetsdk to exactly 37), and you're done.
